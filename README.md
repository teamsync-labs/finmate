# FinMate

Персональный ИИ-помощник по учёту расходов — учебный проект для практики командной разработки.

Пользователь отправляет голосовые сообщения о тратах или фото чеков, а приложение сохраняет расходы в аккаунте и показывает простой список.

**Статус:** Development

## Roadmap

MVP · фаза 1 · «Перестать записывать расходы вручную»

| Неделя | Цель |
|--------|------|
| 1 | ☐ Kickoff & Dev Setup |
| 2 | ☐ Backend, bot — каркасы; первые AI-эксперименты (голос / чек → расход) |
| 3 | ☐ Голос и фото чеков, распознавание, сохранение трат |
| 4 | ☐ Список записанных трат, стабилизация сценария |
| 5 | ☐ UX, обработка ошибок, стабилизация сценариев |
| 6 | ☐ Полировка, публичный релиз, демо MVP |

При необходимости — ещё 1–2 недели на завершение оставшихся задач.

## Структура

```
backend/
  app/               HTTP API, бизнес-логика, интеграции с LLM
  bot/               Telegram-клиент (тот же backend, отдельного API нет)
  tests/
mobile/              мобильное приложение (опционально)
frontend/            сайт-визитка и страница команды
prompts/             промпты, evals, фикстуры для AI-аналитика
docs/                vision и прочая документация
infra/               деплой и окружения
.github/workflows/   CI/CD
```
