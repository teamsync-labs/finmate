# User Flows — happy path

Основные пользовательские сценарии

| Описание сценария | Ожидаемый результат | Компонент |
| --- | --- | --- |
| **Запуск  и ознакомление с приложением**<br>1.Отправить команду /start, или подтвердить действие от бота по его запуску <br> | Бот идентифицировал пользователя.<br>Отобразилось приветственное сообщение,например,(Привет, "имя пользователя"! <br>(из Telegram, если указано) <br>это Finmate bot. Я твой помощник по учету личных расходов)<br>Отображается онбординг по приложению.<br> | Telegram Bot |
| **Прохождение онбординга и начало работы**<br>1.Пользователь подтверждает ознакомление путем нажатия кнопки: "Понял, начать учёт" | Бот готов принимать голосовые сообщения и изображения от пользователя  | Telegram Bot |
| **Пользователь отправляет фото чека через камеру телефон**а<br>1.Нажать на пиктограмму "Скрепка"<br>2.Выбрать камеру<br>3.Сделать снимок<br>4.Отправить боту | Расход успешно распознан и сохранён. Пользователь получает сообщение о сохранении расхода. | Telegram Bot |
| **Пользователь отправляет фото чека через галерею** <br>1.Нажать на пиктограмму "Скрепка"<br>2.Выбрать изображение из соответствующего альбома<br>3.Отправить боту<br> | Расход успешно распознан и сохранён. Пользователь получает сообщение о сохранении расхода. | Telegram Bot |
| **Пользователь отправляет фото чека  как файл**<br>1.Нажать на пиктограмму "Скрепка"<br>2.Выбрать файл с изображением из соответствующей папки <br>3.Отправить боту<br> | Расход успешно распознан и сохранён. Пользователь получает сообщение о сохранении расхода. | Telegram Bot |
| **Пользователь записывает голосовое сообщение о трате**<br>1.Нажать на пиктограмму "Микрофон"<br>2.Записать сообщение<br>3.Отправить боту<br> | Расход успешно распознан и сохранён. Пользователь получает сообщение о сохранении расхода. | Telegram Bot |
| **Пользователь отправляет голосовое сообщение  о трате из файла**<br>1.Нажать на пиктограмму "Скрепка"<br>2.Выбрать аудиофайл из соответствующей папки <br>3.Отправить боту<br> | Расход успешно распознан и сохранён. Пользователь получает сообщение о сохранении расхода. | Telegram Bot |
| **Пользователь отправляет запрос на список затрат** (**расходы были**)<br>1.Вызвать функцию списка команд через интерфейс бота  <br>2.Нажать на "Получить список моих затрат"<br>3.Подтвердить выбор (при необходимости)<br> | Бот отображает информацию о всех тратах пользователя | Telegram Bot |
| **Пользователь запрашивает список затрат** (**расходы отсутствуют**)<br>1.Вызвать функцию списка команд через интерфейс бота  <br>2.Нажать на "Получить список моих затрат"<br>3.Подтвердить выбор (при необходимости)<br> | Бот отображает сообщение об отсутствии затрат <br>(а не пустой список / не ошибку) | Telegram Bot |
